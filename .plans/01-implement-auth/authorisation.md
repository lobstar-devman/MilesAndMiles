Two types of account exist:

1. An Organisational account
2. An Individual account

## Organisation Accounts

Organisational accounts are used by a businesses.

Users in an an organisation have the following permissions:

1. HR
2. Billing
3. Oversight
4. Approval
5. Submit Journey Record
6. Admin

The user who registered the account will given all these permissions.

### Permission Breakdown:

#### HR
- Review employee records and compile reports
- Update employee information

#### Billing
- Update and change account billing information

#### Oversight
- Readonly access to the system

#### Approval
- Approve journeys submitted by users

#### Submit Journey Record
- Submit travel information
- Request approval from a user with the Approval permission

#### Admin
- User Management
- Invite users and manage permissions
- Set default units imperial or metric

## Individual Accounts

An individual user accounts will have no permission and will only be able to use the system to record their  journeys.
